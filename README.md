# Amphibian-Monitoring-Open-Source-Solutions-and-AI-Based-Detection-with-Examples-from-Patagonia
Open-source framework, protocols, and custom BirdNET-Analyzer classifiers for automated amphibian acoustic monitoring. Developed under a WILDLABS &amp; Arm grant, this workflow features data curation, binary model training, and performance validation templates using field data from Patagonian ecosystems.
